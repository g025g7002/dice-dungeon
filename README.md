# 展骰迷宫 · UNFOLD DUNGEON（网页原型 Demo）

基于「投掷定底 + 三维骰子交互展开铺路 + 分岔规避风险 + 魔塔确定性战斗」核心机制制作的网页端可玩原型。**内置中日双语**（默认日语，顶部栏可随时切换「日本語 ⇄ 中文」，选择会被浏览器记住）。

## 启动方式

- 直接用浏览器（Chrome / Edge）打开 `index.html`，或双击 `PLAY.cmd`。
- 多语言：顶部栏点击语言按钮即时切换；也可通过 `index.html?lang=zh` 或 `?lang=ja` 直接指定。

## 核心规则与按键说明

1. **极简骰面与标准 1~6 标号（1对6 · 2对5 · 3对4）**：
   - 每层配备 **4 颗固定骰子**，每颗骰子仅有 **2~3 个面带有内容**（战斗、宝物、回复、奇遇），其余 **3~4 个面全为空地**。
   - 六个面按普通标准骰子标为 `1~6` 号面（严格满足 `1↔6`、`2↔5`、`3↔4` 对立关系），**投掷前**在右侧以**十字型展开图**完整展示六个面的内容。
2. **全流程方向键操控（同时支持鼠标点击）**：
   - `Space`：投掷骰子 / 确认铺路 / 停步进入下一回合
   - `方向键 ↑↓←→`（或 `WASD`）：
     - 放置阶段：直接将底面放到角色对应方向的相邻空格
     - 展开阶段：从当前高亮基准格向对应方向翻折展开新面（按方向键退回已展开的中心格，即可继续向两侧展开**十字形/T字形岔路**）
     - 移动阶段：所有上下左右相邻的道路格全部互相连通（不局限于骰子展开顺序），按方向键或鼠标自由选路前进（仅禁止走回头路踏上已访问格）
   - `Q / E`：逆时针 / 顺时针水平旋转骰子
   - `Z / Backspace`（或右键）：撤回上一步展开
3. **分岔规避与反零战斗直通机制**：
   - 可利用十字形展开制造三条岔路，将高损血战斗面甩在不走的侧翼死胡同里规避。
   - 数学约束：`9×9` 地图从 `(0,0)` 到终点 `(8,8)` 邻格最短需踏过 **15 格**，而 4 颗骰子的非战斗格（空地+增益）总计仅 **14 格**（`< 15`），若规避每一次战斗则剩余道路格必然无法抵达终点。
